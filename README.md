## Description

This project is Assignment 4 for Web Technologies.
The goal is to create HTML forms using HTML5, Bootstrap 5,
CSS and JavaScript.

## Tasks

### Task 0 - Contact Form
A simple HTML contact form with name, email and message fields.

### Task 1 - HTML5 Validation
A contact form with required fields and email validation.

### Task 2 - Bootstrap Form
A contact form styled using Bootstrap 5 and its grid system.

### Task 3 - Bootstrap Validation
A form with validation feedback messages using Bootstrap and JavaScript.

### Task 4 - Registration Form
A registration form with first name, last name, email,
password, gender, hobbies and country selection.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a browser.
4. Use the navigation bar to switch between tasks.
